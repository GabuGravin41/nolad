### Decision trees

A regression tree partitions the data by tests of the form $x_j < t$ until each leaf contains a small group of examples, and predicts a constant in each leaf. A single deep tree overfits easily, and its prediction is piecewise constant.

### Boosting as gradient descent in function space

Start from a constant prediction $F_0$. At each round $m$, fit a small tree $h_m$ and add it with a learning rate $\nu$:

$$
F_m(x) = F_{m-1}(x) + \nu\, h_m(x).
$$

Which tree? For a loss $\ell(y, F)$, compute for each example the negative gradient with respect to the current prediction,

$$
r_i = -\left.\frac{\partial\,\ell(y_i, F)}{\partial F}\right|_{F = F_{m-1}(x_i)},
$$

and fit $h_m$ to the $r_i$ by least squares. For the squared error $\ell = \tfrac12 (y - F)^2$, the negative gradient is the residual $r_i = y_i - F_{m-1}(x_i)$. For the log loss with $F$ the logit and $p = \sigma(F)$, $\ell = -[y \log p + (1-y)\log(1-p)]$ and $\partial\ell/\partial F = p - y$, so $r_i = y_i - p_i$. Each tree approximates a step of gradient descent in the space of functions, with step size $\nu$.

<Deep title="Second-order boosting: how XGBoost and LightGBM choose leaf values" kind="math">

Expand the loss to second order around the current prediction, with $g_i = \partial\ell/\partial F$ and $h_i = \partial^2\ell/\partial F^2$:

$$
\ell(y_i, F + f) \approx \ell(y_i, F) + g_i f + \tfrac12 h_i f^2 .
$$

A tree assigns the same value $w_j$ to all examples in leaf $j$. With an L2 penalty $\tfrac12\lambda w_j^2$, the part of the objective that depends on $w_j$ is

$$
\Big(\sum_{i\in j} g_i\Big) w_j + \tfrac12\Big(\sum_{i\in j} h_i + \lambda\Big) w_j^2,
$$

minimised at

$$
w_j^\star = -\frac{G_j}{H_j + \lambda}, \qquad G_j = \sum_{i\in j} g_i,\ H_j = \sum_{i\in j} h_i,
$$

Substituting $w_j^\star$ back, the objective of leaf $j$ decreases by $\tfrac12 G_j^2/(H_j + \lambda)$. A split of a leaf into left and right children is therefore scored by the gain

$$
\text{gain} = \frac12\left[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\right] - \gamma,
$$

where $\gamma$ is a penalty per additional leaf. For log loss, $g_i = p_i - y_i$ and $h_i = p_i(1 - p_i)$.

**Example.** A leaf contains four examples with current prediction $p = 0.5$ and labels $1, 1, 1, 0$. Then $g = (-0.5, -0.5, -0.5, 0.5)$, $G = -1$, $h_i = 0.25$ and $H = 1$. With $\lambda = 1$, $w^\star = 1/2 = 0.5$: the logit of these examples increases by $0.5 \nu$, moving $p$ towards the observed fraction of 0.75.

### The three libraries

- **XGBoost** introduced the regularised second-order formulation above.
- **LightGBM** grows trees leaf-wise and bins features into histograms, which makes it very fast on large data.
- **CatBoost** encodes categorical features with ordered target statistics and uses symmetric trees; its authors report that it needs less tuning.

All three run on GPUs. The ISIC 2024 winner trained 150 gradient-boosted models in under 20 minutes. **py-boost**, used by the CAFA 5 runner-up, is a GPU implementation designed for thousands of outputs at once.

### Suitability for tabular data

Tabular features are heterogeneous (an age, a colour index, a count, a category), their scales are not comparable, and many relationships take the form of thresholds. A tree split depends only on the order of a feature's values, so trees are invariant to monotone transformations of each feature; they handle missing values and mixed feature types without preprocessing. In ISIC 2024, the image models' outputs were fed as additional columns into gradient-boosted trees, which combined them with lesion colour, shape and patient-level context.
